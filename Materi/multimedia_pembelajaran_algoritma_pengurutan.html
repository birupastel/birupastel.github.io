Memahami Algoritma Pengurutan (Sorting)

Pengurutan data dapat dilakukan secara Ascending (menaik: kecil ke besar) atau Descending (menurun: besar ke kecil). Pelajari konsep logika dan kode programnya di bawah ini!

1

Bubble Sort (Metode Apung)

Pertukaran Bertetangga

💡 Analogi Dunia Nyata: Barisan Siswa

Seperti dua siswa bertetangga saat baris upacara. Jika tinggi siswa kiri > kanan, mereka saling bertukar tempat. Elemen terbesar bertahap "mengapung" ke ujung kanan.

Algoritma ini membandingkan dua elemen bertetangga data[j] dan data[j+1]. Jika posisinya melanggar aturan urutan, lakukan penukaran (swap).

📈 Ascending (Menaik):

Ditukar jika data[j] > data[j+1]. Elemen terbesar bertahap mengapung ke ujung kanan.

📉 Descending (Menurun):

Ditukar jika data[j] < data[j+1]. Elemen terkecil bertahap mengapung ke ujung kanan.

Implementasi Kode Program: 
// Bubble Sort (Ascending) - C++
for (i=n-1; i>0; i--) {
    for (j=0; j data[j+1]) {
            temp = data[j];
            data[j] = data[j+1];
            data[j+1] = temp;
        }
    }
}

Selection Sort (Metode Seleksi)

Pencarian Indeks Target

Seperti mencari kartu nilai terkecil/terbesar dari sisa kartu di tangan, lalu langsung menukarnya ke posisi target awal di sebelah kiri.

Mencari posisi indeks nilai ekstrim (terkecil/terbesar) pada sisa larik, lalu menukarnya langsung ke posisi indeks target i.
