Algoritma #1

Linear Search (Pencarian Berurutan)

Algoritma ini mengecek setiap elemen dari indeks paling awal (0) hingga akhir satu per satu sampai elemen yang dicari ditemukan atau seluruh array habis diperiksa.

Kompleksitas Waktu: O(n)
Cepat Lambat
Visualisasi Deret Array: Langkah: 0
Belum Didekati
Sedang Diperiksa
Ditemukan!
Bukan Target
Klik 'Jalankan' atau 'Maju' untuk memulai proses simulasi Linear Search.
C++ Implementation 
#include <iostream>
using namespace std;

int linearSearch(int arr[], int size, int target) {
    for (int i = 0; i < size; i++) {
        if (arr[i] == target) {
            return i; // Ditemukan, kembalikan indeks
        }
    }
    return -1; // Tidak ditemukan
}

int main() {
    int data[] = {12, 25, 38, 41, 53, 67, 72};
    int n = sizeof(data) / sizeof(data[0]);
    int target = 41;

    int result = linearSearch(data, n, target);
    if (result != -1)
        cout << "Elemen ditemukan pada indeks: " << result << endl;
    else
        cout << "Elemen tidak ditemukan." << endl;

    return 0;
}
Python Implementation 
def linear_search(arr, target):
    for i in range(len(arr)):
        if arr[i] == target:
            return i  # Ditemukan, kembalikan indeks
    return -1  # Tidak ditemukan

# Contoh Penggunaan
data = [12, 25, 38, 41, 53, 67, 72]
target_val = 41

idx = linear_search(data, target_val)
if idx != -1:
    print(f"Elemen ditemukan pada indeks: {idx}")
else:
    print("Elemen tidak ditemukan.")

Binary Search (Pencarian Biner)

Algoritma membagi ruang pencarian menjadi dua bagian secara berulang dengan membandingkan nilai tengah (Mid) terhadap target yang dicari.

Kompleksitas Waktu: O(log n)

Cepat Lambat
Visualisasi Indeks & Pointer: Langkah: 0
Low (Batas Kiri)
Mid (Titik Tengah)
High (Batas Kanan)
Dieliminasi / Dibuang
Klik 'Jalankan' atau 'Maju' untuk mengamati eliminasi variabel Low, Mid, dan High.
C++ Implementation 
#include <iostream>
using namespace std;

int binarySearch(int arr[], int size, int target) {
    int low = 0;
    int high = size - 1;

    while (low <= high) {
        int mid = low + (high - low) / 2;

        if (arr[mid] == target)
            return mid; // Ditemukan
        
        if (arr[mid] < target)
            low = mid + 1; // Cari di setengah bagian kanan
        else
            high = mid - 1; // Cari di setengah bagian kiri
    }

    return -1; // Tidak ditemukan
}

int main() {
    int data[] = {11, 19, 24, 33, 45, 52, 68, 77, 85, 91, 98};
    int n = sizeof(data) / sizeof(data[0]);
    int target = 45;

    int result = binarySearch(data, n, target);
    if (result != -1)
        cout << "Elemen ditemukan pada indeks: " << result << endl;
    else
        cout << "Elemen tidak ditemukan." << endl;

    return 0;
}
Python Implementation 
def binary_search(arr, target):
    low = 0
    high = len(arr) - 1

    while low <= high:
        mid = (low + high) // 2

        if arr[mid] == target:
            return mid  # Ditemukan
        elif arr[mid] < target:
            low = mid + 1  # Buang bagian kiri
        else:
            high = mid - 1  # Buang bagian kanan

    return -1  # Tidak ditemukan

# Contoh Penggunaan
data = [11, 19, 24, 33, 45, 52, 68, 77, 85, 91, 98]
target_val = 45

idx = binary_search(data, target_val)
if idx != -1:
    print(f"Elemen ditemukan pada indeks: {idx}")
else:
    print("Elemen tidak ditemukan.")
